# Actos - guía visual interna

## Dirección

Actos debe sentirse como una red social útil, contemporánea y privada: tecnología + humanidad. No debe parecer una app infantil, escolar, institucional ni de voluntariado clásico.

## Paleta

- Fondo: `#f6f8fb`, claro, neutro, rápido de leer.
- Texto principal: `#101827`.
- Texto secundario: `#647084`.
- Azul profundo: `#10233f`, para marca, chat y confianza.
- Azul vibrante: `#2458ff`, para acciones principales.
- Verde energético: `#16b887`, para afinidad, sesión activa y señales positivas.
- Coral: `#ff6b4a`, para acentos humanos y momentos de atención.
- Violeta moderno: `#6f56ff`, solo como apoyo en gradientes sutiles.

## Componentes

- Botón primario: gradiente azul/violeta, alto contraste, borde redondeado de 12px.
- Botón secundario: blanco, borde gris suave, texto azul profundo.
- Cards: blancas o gris muy claro, borde fino, radio de 16-18px y sombra suave.
- Tags: chips compactos para zona, modo, seguridad y categorías.
- Match: siempre debe mostrar qué ofrece, qué necesita y una señal visual de compatibilidad.
- Perfil/cuenta: debe vivir en una solapa discreta, no competir visualmente con el acto.
- Chat: debe llamarse “Mensajes de matches” o “Mensajes”, nunca parecer soporte técnico.

## Tono visual

Simple, social, moderno, liviano. Animaciones mínimas: hover suave y apertura/cierre sin distraer. Mobile first: formularios claros, cards de lectura rápida y acciones visibles.
